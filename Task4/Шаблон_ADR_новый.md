### <a name="_b7urdng99y53"></a>**Название задачи:** Передача ставок в кол-центры
### <a name="_hjk0fkfyohdk"></a>**Автор:** Команда цифровой трансформации
### <a name="_uanumrh8zrui"></a>**Дата:** 2025-12-03
### <a name="_3bfxc9a45514"></a>**Функциональные требования**

|**№**|**Действующие лица или системы**|**Use Case**|**Описание**|
| 1 | Клиент, колл-центры | Консультация клиентов по текущим ставкам банка | Нужно предоставить доступ к текущим депозитным ставкам для операторов кол-центра |
| 2 | Клиент, колл-центры | Консультация клиентов по текущим ставкам банка | Доступ до текущих ставок банка должен быть как у партнерского, так и у внутреннего кол-центра |
| 3 | Сотрудники бэк-офиса, система депозитов | Управления ставками банка | Менеджеры могут обновлять и корректировать депозитные ставки банка |

### <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**

|**№**|**Требование**|
| 1 | Интерфейс загрузки ставок для менеджеров бэк-офиса поддерживает загрузку из xls-файла |
| 2 | Должен быть метод в системе депозитов для отправки файла со ставками |
| 3 | После загрузки, автоматически генерируется файл со ставками для кол-центров |
| 4 | Система кол-центров получает файл со ставками банка по SFTP |
| 5 | Доступ до файлов должен бять как у партнерского, так и у внутреннего кол-центра |

### <a name="_qmphm5d6rvi3"></a>**Решение**

[C4._Context.pulm](diagrams/C4_Context.puml)
[C4._Container.pulm](diagrams/C4_Container.puml) 

Необходимым и достаточным будет добавление отправки файлов ставки во внешнее хранилище, откуда будут запрашивать ставки операторы кол-центров.
Хранилище конечно же будет защищено и доступно только для операторов. Также имеет смысл перенести управление депозитами для менеджеров бэк-офиса на сервис депозитов.  
### <a name="_bjrr7veeh80c"></a>**Альтернативы**

1. Реализовать передачу ставок по E-mail вручную менеджерами. Не подходит т.к. нужно автоматизировать процесс.
2. Отдавать ставки по API не подходит для партнерского колл-центра.
3. Сделать интерфейс для расчета ставок операторами кол-центров. Не подходит для MVP

**Недостатки, ограничения, риски**

1. После обновления ставок менеджером, операторы могут отдавать некорректные ставки, пока не заберут новый файл ставок
2. Разные операторы в зависимости от частоты обновления файла ставок могут давать разную инфу по ставкам
3. Если они часто будут забирать файл ставок, для каждого клиента, то возрастет нагрузка на сервер в случае большого количества звонков
